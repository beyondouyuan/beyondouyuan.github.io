01 · 机房动力环境监控大屏

机房要把温湿度、漏水、空调、UPS 与配电、告警事件压进一屏，值班电脑、车间电视、手机都要能看。

一套 Vue3 + TypeScript + ECharts 代码适配 PC / 移动 / 车间大屏 / 电视四端，定尺等比缩放 + 居中留白承接不同分辨率
大屏端用 Three.js 做机房 3D 数字孪生：透视机柜、悬浮温度标签、告警脉冲环，另留 2D 平面降级开关；电视端封装 APK 常驻播放

结果：现场 7×24 值班可用；设备总览 26 台、5 类告警面板一屏可读，告警从翻列表变成扫一眼。

技术栈：Vue3 · TypeScript · ECharts · Three.js · 定尺等比缩放　|　证据：work-idc-3d.png 为 idc-monitor 前端 dist 本地运行、renderMode=3d 的 Three.js 场景截图；work-idc-screen.png 是 TV 端 2D 降级态对照
02 · 聚合广告 SDK · 三端桥接
角色：架构设计 + 三端桥接

同一套广告能力要给原生、Flutter、RN 三种技术栈的 App 复用，且每个 App 接入的广告平台组合不同。

Loader / Provider / Proxy 三层架构，插件层只保留通道、句柄与事件转发，复用原生竞价与投放能力
Flutter 用 MethodChannel / EventChannel 双通道 + 13 类事件枚举；RN 用 NativeModule / RCTEventEmitter；Android 桥接层 Kotlin

结果：Android / iOS 各 3 类广告位（激励、插屏、Native）在真机上跑通了 loadSuccess → show → adShow 三步；以 adShow 为成功判据，Flutter 单轮验收从 184s 压到 35s。开屏与 Banner 仍需后台配位，iOS 侧 Swift module 工厂符号问题仍在排查。

技术栈：Kotlin · Flutter · React Native · 聚合 SDK · 竞价 / 瀑布流　|　证据：docs/discovery/2026-10-28 双端验收报告 · apps/projects/uju_flutter_sdk、uju_rn_sdk

合作流程

01　需求澄清（1–2 天）：确认目标、范围、验收标准与依赖，输出一页需求确认单。
02　方案与报价（双方确认后开工）：技术方案、里程碑拆分、工期与报价。
03　里程碑开发（按周交付）：每周给可运行版本，随时可演示，不接受最后一天才看到东西。
04　验收与交付（对照清单逐项）：交付源码、部署文档与接入说明。
05　交付后 30 天（缺陷免费修复）：需求变更单独评估。
